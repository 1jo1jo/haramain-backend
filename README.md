Wajbat Alharamain 🕋

About the Project

Waibat Alharamain is an ongoing academic project aimed at developing a web and mobile application to facilitate meal requests and donations for Hajj and Umrah visitors.

The platform aims to connect meal providers with people who need meals, helping organize meal requests, orders, and related processes through a digital solution.

Project Objectives

• Simplify meal request and donation processes.
• Organize meal orders and restaurant management.
• Support coordination between restaurants and couriers.
• Provide a user-friendly digital experience for Hajj and Umrah visitors.

Technologies Used

• Backend Development
• Database Management
• REST API

Additional technologies will be listed as development progresses.
